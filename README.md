**32-bit Pipelined Multiplier – Verilog & Zybo FPGA**

**Overview**

Implementation of a 32-bit Pipelined Multiplier using Verilog, designed to improve arithmetic processing through pipelining and implemented on the Zybo FPGA development board.

**Function**
The design performs 32-bit multiplication using a pipelined architecture, allowing arithmetic operations to be processed across multiple clock stages.

**Features**
* 32-bit multiplication
* Pipelined architecture
* Sequential processing
* FPGA hardware implementation

* `p_m32.v` – Verilog design
* `tb_p_m32.v` – Testbench
* 'Makefile'

* 'arty.xdc'
* 'p_m32.bit'
* `screenshots/` – Simulation and Zybo FPGA implementation results

**Tools & Technologies**
Verilog • Zybo FPGA • Vivado • Digital Logic Design

**Result**
The 32-bit Pipelined Multiplier was verified through simulation and successfully implemented and tested on the Zybo FPGA board.
